# Italiano 1500

A free, offline, mobile-first study app for the **1,500 most frequent Italian words** — sister app to
[Latin 1400](https://ericianni.github.io/latin-diederich-vocab/).

**Live:** https://ericianni.github.io/italiano-1500/

- **Cards** in both directions (Italian → English, then English → Italian with optional typing), Leitner spaced
  repetition, graded right/wrong only. 10 new words a day by default; sessions capped at 30 cards.
- **Drills**: present, passato prossimo (avere/essere + participle agreement), imperfetto, future — regular -are/-ere/-ire,
  -isc- verbs, spelling-change verbs and the main irregulars; definite/indefinite articles; adjective agreement.
  Type, Identify (chips) or Mix; free practice weighted toward weak spots; "New word" / "New form" tags.
  A form with more than one reading (sono: io or loro) accepts any one; the optional And…? follow-up asks for the others.
- **Learn**: 11 short lessons and a cheat sheet. Every table is generated by the same morphology engine that grades answers.
- **Test this word**, from the word list: that word’s flashcards (both directions) and form drills, without saving progress.
- **Sentences in drills** (off until you turn it on): about one question in seven is a short rule-built sentence for a trip to Rome, from words you have already seen.
- Offline PWA (service worker cache `italiano1500-v14`), progress in localStorage with export/import.

## Structure

```
core/            language-agnostic, reusable (UMD: browser globals + Node)
  srs.js           Leitner scheduler (right/wrong only)
  drillpick.js     weighted free-practice picking, weak spots
  drillsession.js  drill sets with one re-ask per miss
  store.js         localStorage + export/import
  packs.js         word-pack loader
  ui.js            DOM helpers (accent keys, chips, overlay, grading buttons)
lang/it/         Italian layer
  morph.js         morphology engine: articles, plurals, adjectives, 4 tenses, participles, auxiliaries
  drills.js        drill units/questions/answer checking built on morph.js
  sentences_lexicon.js   hand-tagged lexicon for the sentence engine
  sentences.js     rule-based sentence engine (no model, no network)
  lessons.js       lessons (text + table specs + quizzes)
data/packs/
  index.json       list of packs
  core/manifest.json, core/words.json   the core 1,500-word pack
app.js           app shell (tabs: Cards, Learn, Drills, Cheat sheet, Words, About)
tools/           build pipeline for the word list (frequency list → lemmas → curated entries)
tests/           run.js (unit + data + drill generation), datacheck.js (cross-check vs Wiktionary/Morph-it!), smoke.js (headless Chrome)
```

Adding a pack: create `data/packs/<id>/manifest.json` + `words.json` (same entry fields as core) and list it in
`data/packs/index.json`. Non-core word ids are prefixed `<id>/` so progress never collides.

## Tests

```
npm test          # morphology, data, SRS, drills, lessons, packs, sentences, service-worker asset list
npm run smoke     # drives every tab in headless Chrome (needs google-chrome)
```

## Android app (Capacitor)

The same app is wrapped as a native Android app (`io.github.ericianni.italiano1500`, versionCode 1, versionName `v14-android-1`). Web files are bundled into the APK, so it works offline from first launch. The service worker still updates the site at GitHub Pages; inside the app it is not registered.

This is the first Italian APK. It is signed locally with the existing debug keystore on the maintainer’s computer (the same key as the Latin 1400 APKs). No keystore is stored in this repo.

Build (Node, JDK 21, Android SDK platform 36):

```sh
npm install
JAVA_HOME=/opt/jdk21 ANDROID_HOME=/opt/android-sdk npm run android:debug
# APK: android/app/build/outputs/apk/debug/app-debug.apk
```

`npm run build:web` only copies the PWA into `www/`. `npm run android:sync` copies and syncs Capacitor, and does not compile or sign.
