# Inferno text

`inferno.txt` is the verse text of the Inferno, one line per verse, labeled `canto.line`.

Source: Project Gutenberg eBook #997, *Divina Commedia di Dante: Inferno*, Dante Alighieri. Release date August 1, 1997; updated April 10, 2021. https://www.gutenberg.org/ebooks/997

License: public domain in the United States. The Project Gutenberg license applies to the eBook packaging; the poem itself (Dante, died 1321) is public domain everywhere.

This is not Giorgio Petrocchi’s critical edition (*La Commedia secondo l’antica vulgata*, 1966–67), which is still under copyright. The file was checked against the standard 34-canto, 4,720-line numbering used by that edition: Canto I has 136 lines, Canto XXXIV has 139, and the last line is *E quindi uscimmo a riveder le stelle* (34.139).

Lemmatization used Morph-it! 0.4.8 (Marco Baroni and Eros Zanchetta), CC BY-SA 2.0 and LGPL. The lexicon itself is not stored in this repo. English glosses were written for this app (CC BY-SA 4.0).
